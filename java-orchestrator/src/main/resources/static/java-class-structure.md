## Java Orchestrator: Architecture Index

### 1. Project Package Structure

* `com.rag.orchestrator`
* **`.model`** *(Data Transfer Objects / Entities)*
* **`.service`** *(Core business logic like file scanning)*
* **`.client`** *(HTTP clients to talk to your Python FastAPI)*
* **`.scheduler`** *(Cron jobs to automate the scanning)*



---

### 2. Class Diagrams & Method Signatures

Below are the architectural blueprints for the four core classes you will need.

#### A. The Data Model: `DocumentPayload`

This is a standard POJO (Plain Old Java Object). It holds the metadata of the PDF file before it gets sent over to Python as a JSON object.

```text
+---------------------------------------------------+
|                  DocumentPayload                  |
+---------------------------------------------------+
| - fileName: String                                |
| - absolutePath: String                            |
| - fileSizeKb: long                                |
| - lastModified: LocalDateTime                     |
+---------------------------------------------------+
| + DocumentPayload(String, String, long, Date)     |
| + getFileName(): String                           |
| + getAbsolutePath(): String                       |
| + getFileSizeKb(): long                           |
| + getLastModified(): LocalDateTime                |
| + toString(): String                              |
+---------------------------------------------------+

```

#### B. The Business Logic: `FileScannerService`

This class is responsible for reading your local `data/sops` directory, filtering for `.pdf` files, and converting them into `DocumentPayload` objects.

```text
+---------------------------------------------------+
|                FileScannerService                 |
+---------------------------------------------------+
| - targetDirectory: String                         |
| - supportedExtension: String (".pdf")             |
+---------------------------------------------------+
| + scanDirectory(String path): List<DocumentPayload>|
| - isValidPdf(File file): boolean                  |
| - createPayload(File file): DocumentPayload       |
+---------------------------------------------------+

```

* **`scanDirectory(String path)`**: Takes the folder path as a parameter, loops through the files, and returns a List of valid document objects.
* **`isValidPdf(File file)`**: A private helper method to ensure the file isn't hidden and actually ends in `.pdf`.

#### C. The API Client: `PythonApiClient`

This class acts as the bridge. It takes the payload generated by the scanner and makes an HTTP POST request to your Python server.

```text
+---------------------------------------------------+
|                  PythonApiClient                  |
+---------------------------------------------------+
| - pythonEngineUrl: String                         |
| - restTemplate: RestTemplate                      |
+---------------------------------------------------+
| + sendForProcessing(DocumentPayload payload): boolean |
| - buildHttpHeaders(): HttpHeaders                 |
+---------------------------------------------------+

```

* **`sendForProcessing(DocumentPayload payload)`**: Takes the document model, serializes it to JSON, sends it to Python, and returns `true` if Python successfully received it.

#### D. The Automation: `ScanScheduler`

Instead of manually clicking a button, this class uses Spring's `@Scheduled` annotation to run the scanner automatically (e.g., every 5 minutes) to see if you dropped a new PDF into the folder.

```text
+---------------------------------------------------+
|                   ScanScheduler                   |
+---------------------------------------------------+
| - fileScannerService: FileScannerService          |
| - pythonApiClient: PythonApiClient                |
+---------------------------------------------------+
| + executeScheduledScan(): void                    |
+---------------------------------------------------+

```

* **`executeScheduledScan()`**: Takes no parameters. It wakes up on a timer, calls `scanDirectory()`, and feeds any found PDFs into `sendForProcessing()`.
